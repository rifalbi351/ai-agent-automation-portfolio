# Contributing to AI Agent & Automation Portfolio

Thank you for your interest in contributing! This repository serves as a professional portfolio showcasing my work in AI agents, automation, and infrastructure.

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest improvements
- Include detailed descriptions, steps to reproduce, and expected behavior
- For security issues, please email directly rather than opening public issues

### Suggesting Enhancements
- Open an issue with the label `enhancement`
- Describe the proposed change and its benefits
- Include examples or references where applicable

### Code Contributions
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature-name`)
3. Make your changes with clear, documented code
4. Commit with descriptive messages (`git commit -m 'Add: detailed description'`)
5. Push to your fork and submit a Pull Request

## Development Guidelines

### Code Style
- Python: Follow PEP 8 style guide
- Shell: Use shellcheck for bash scripts
- Documentation: Clear comments and README updates

### Commit Message Format
```
Type: Brief description

Detailed explanation if needed

Types:
  Add: New feature or file
  Fix: Bug fix
  Update: Modification to existing feature
  Docs: Documentation only
  Refactor: Code restructuring without behavior change
  Test: Adding or updating tests
```
